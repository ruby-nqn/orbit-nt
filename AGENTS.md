# Repository instructions

## GitHub authorship and contributor credits

- Do not list Codex, ChatGPT, this assistant, or an AI/bot identity as a contributor, author, committer, or co-author for this repository.
- Use the user's existing Git author and committer identity. Do not change Git identity settings to an assistant or bot identity.
- Do not add AI attribution trailers, including `Co-authored-by`, `Signed-off-by`, or generated-by credits identifying an AI assistant, to commits or pull requests.
- Do not add the assistant to contributor lists, README acknowledgments, release notes, or other project credits.
- Preserve legitimate human authorship and attribution.
